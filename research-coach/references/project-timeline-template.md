# 项目时间规划模板（从截稿日倒推）

| 节点 | 要完成的事 | 预期完成 |
|---|---|---|
| 开始 | | YYYY-MM-DD |
| 节点1 规划课题 | 建立视野；想清楚 SOTA 在哪些指标上还没做好；列出可做的课题，评估竞争程度和发展空间，选一个和自己能力匹配的 | |
| 节点2 明确失败案例和技术挑战 | 在新数据、新设置下跑 SOTA 代码，找到能启发技术贡献的失败案例；回答"这个任务的设置、输入、输出各有什么独特之处" | |
| 节点3 用第一性原理设计方案 | 分析 SOTA 不 work 的核心原因；列出和这个难点相关的所有技术；把它们排列组合成大量候选 pipeline；多和人讨论；挑出最可能 work、最有新意的一个 | |
| 节点4 验证性实验 | 按 SGD 流程循环：提 idea → 读文献、讨论 → 实现 → 探索性实验 → 分析结果得到梯度 → 改进 | |
| 节点5 做出亮点 | 规划论文要展示的 demo 和应用，继续用 SGD 流程把效果做好 | |
| 节点6 写论文、投稿 | 按写作规划 9 步执行：先倒推故事再正推，先做消融再做对比，边写边做实验 | 截稿日 |

**经验比例**（以课件里那个约半年的 CVPR 项目为例）：节点 1 约 1 周，节点 2 约 2 周，节点 3 约 2 周，节点 4 约 2 个月，节点 5 约 1 个月，节点 6 约 1.5 个月。时间紧的话先压缩节点 5，节点 2 和 3 不要省。

**每个节点的退出条件**：交付物写完，并且给一个懂行的人讲过一遍。
